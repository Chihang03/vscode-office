## 功能

命令面板、编辑器标题栏、编辑器右键菜单、资源管理器文件右键菜单均提供 PDF 导出入口；自定义编辑器原有导出菜单继续可用。先选择保存位置，再同步并保存待保存内容。

每页左上角显示源文件名，右上角显示本地导出日期 YYYY-MM-DD，底部居中显示当前页 / 总页数。不生成目录或 PDF 书签，正文 [toc] 目录指令不会生成目录，代码块中的字面量保留，不为移除目录修改源文件。

等待流程图、字体和图片后渲染；失败时关闭浏览器并清理临时文件。浏览器路径配置使用 `kieran-document-studio.chromiumPath`，需要已安装 Chrome、Edge 或 Chromium。
