## 功能

Markdown 标题生成一至六级分层书签，保留准确跳转位置和语义标题标签，并请求打开大纲侧栏。正文不插入目录，[toc] 继续不渲染。每页左上角为文件名，右上角为本地导出日期，底部为当前页 / 总页数。查看器或用户偏好可能覆盖侧栏自动展开请求。

CSV、TSV、XLSX、XLS、ODS 的当前工作表第一次显示时自动适配列宽。其他工作表第一次激活时才适配，恢复上次查看位置直接处理恢复的那一张。切回、编辑和调整窗口不会覆盖已手动调整的列宽。自动适配不产生 dirty、撤销记录或额外的工作表撤销快照。工作簿解析仍加载全量数据，未量化大型真实工作簿的峰值内存。
